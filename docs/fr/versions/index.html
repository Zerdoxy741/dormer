Vérifier ton téléchargement

Dormer n'est pas notarisé par Apple : c'est pour ça que macOS affiche un avertissement à la première ouverture. Voici comment vérifier que ton fichier vient bien de son créateur et n'a pas été modifié.

1. L'empreinte du fichier

Dans le Terminal, dans le dossier où se trouve le fichier :

shasum -a 256 Dormer.zip

Le résultat doit être identique à l'empreinte SHA-256 de ta version ci-dessous. Elle est aussi écrite dans les notes de la version sur GitHub.

2. Le certificat de signature

Toutes les versions sont signées avec le même certificat, Notchy Local Signing. Son empreinte SHA-256 :

01:19:CA:20:48:E5:6E:A9:2A:A3:A7:BF:A0:16:26:B9:9C:23:57:00:12:7B:69:78:B7:00:5A:7C:EC:6F:76:8C

Pour la comparer :

codesign -d --extract-certificates=/tmp/dormer /Applications/Dormer.app
openssl x509 -inform der -in /tmp/dormer0 -noout -fingerprint -sha256

Dormer fait lui-même cette vérification à chaque mise à jour : il refuse toute nouvelle version qui n'est pas signée avec ce certificat.

Avec Homebrew

brew install --cask zerdoxy741/dormer/dormer

Homebrew vérifie l'empreinte du fichier pour toi. L'avertissement de macOS apparaît quand même à la première ouverture.
